Explore — discovery wireframe & component spec

Build-ready blueprint for the flagship discovery system — the AI is the center, not the search bar. This is a shared browse system re-skinned across the existing vertical routes (/restaurants · /cafes · /nightlife · /rentals), not a new /explore page. Layout: nav → tabs → full-width AI Concierge band → Results │ sticky Map. IA companion: ia-journey.md · tokens: design-system.md · images: images.md.

12 sections + anatomy light mode · pale-teal placeholders teal = interactive · gold = AI + stars AI-in-center · §3.3 EN only · Phase 1

Global layout rules — Explore

  • The stack: nav → vertical tabs → full-width AI band → Results │ sticky Map (never bury the AI under cards)
  • Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8; split = grid lg:grid-cols-[1fr_minmax(360px,420px)]
  • Map is co-primary with the concierge — sticky right, hover ↔ pin live sync (the Mindtrip moat)
  • Re-skin, don't add a route: tabs switch the vertical; one <VenueCard> + one map serve all verticals
  • Palette discipline: teal everywhere interactive + map pins; gold only for the ✦ AI band/insights + rating stars; category = glyph + label, not color
  • Don't replace: concierge = CopilotKit v1 (restyle only); map = @vis.gl ChatMap (mapId + X-Goog-FieldMask)
  • AI Insight = GROUNDED only (saved places · time · neighborhood · vertical); never fabricated co-visitation — hide when no signal
  • A11y/perf: prefers-reduced-motion; skeletons on every async row + map tiles; mobile collapses AI → sticky input + FAB, map → toggle
