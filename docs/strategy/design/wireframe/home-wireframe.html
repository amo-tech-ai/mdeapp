Home page — wireframe & component spec

Build-ready blueprint for /. Visual companion to 01-marketing.md. Each band = one section: low-fi layout on the left, the component to use + score + link + UX/layout notes on the right. Scores are MDE-fit judgment (fit 50 · production-ready 30 · low restyle effort 20), not scraped ratings.

14 sections light mode · pale-teal placeholders teal = interactive · gold = AI + stars EN only · Phase 1

Global layout rules

  • Container: max-w-7xl mx-auto px-4 sm:px-6 lg:px-8
  • Section rhythm: py-16 md:py-20 lg:py-24, alternate bg-background / bg-muted/40
  • Card grid: grid gap-4 sm:grid-cols-2 lg:grid-cols-3/4; mobile → horizontal scroll-snap
  • Images: one pale-teal placeholder (#E1F6F2); real Places photos fill in prod
  • Palette discipline: teal everywhere interactive; gold only for AI concierge + rating stars; category = glyph + label, not color
  • Don't replace: the concierge = CopilotKit (restyle only); the map = @vis.gl ChatMap (mapId + X-Goog-FieldMask)
  • A11y/perf: prefers-reduced-motion on hero + marquee; skeletons on every async row
  • Build order: P0 primitives → hero + search → map teaser → discovery rows → host/CTA/footer
