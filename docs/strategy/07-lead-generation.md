## 7.2 Two funnels

### Consumer (demand) funnel
```
SEO / social / AI-referral → concierge chat → booking/ticket →
WhatsApp re-engagement → MDE+ perks / repeat
```

### Business (supply/client) funnel
```
"Claim your listing" / free AI audit → agency call →
Pro/Business subscription → marketplace transactions → upsell/referral
```

| Funnel | North-star | Primary channels |
|---|---|---|
| Consumer | Weekly active concierge users + bookings | SEO, social, hotels, WhatsApp loops |
| Business | New paying logos + NRR | Free audit, BD, expat groups, referrals |

## 7.3 The cheapest CAC: dogfooding

> Every asset MDE generates for itself (IG posts, SEO pages, WhatsApp flows) simultaneously **proves the AI-marketing product** and **pulls in the next client**. Marketing spend and product demo are the same activity.

## 7.4 Programmatic SEO blueprint (highest-leverage organic)

| Page template | Example | Intent captured |
|---|---|---|
| `/[neighborhood]/restaurants` | El Poblado restaurants | Local + tourist dining |
| `/things-to-do/[attraction]` | Comuna 13 tour | Activity booking |
| `/events/[category]/[month]` | Nightlife events June | Event discovery |
| `/rentals/[neighborhood]` | Laureles apartments | Expat/nomad housing |
| `/[business-name]` | Individual venue page | Branded + claim funnel |

- Auto-generate from Supabase + Places data; keep content genuinely useful (AI summaries, maps, booking CTA).
- Each page is both a demand surface *and* a "claim this listing" supply hook.

## 7.5 Funnel metrics to instrument from day one

| Metric | Why |
|---|---|
| CAC by channel | Kill losers, double winners |
| Conversion by funnel stage | Find the leak |
| Concierge → booking rate | Core demand health |
| Audit → retainer rate | Core supply health |
| WhatsApp opt-in rate | Re-engagement capacity |
| Referral coefficient | Virality / organic growth |
| CAC payback (months) | Should be < 3 (model targets ~1) |
