## Summary

Wired four previously ignored `venue_signals` columns into `computeSignalBoost` + extended `parseIntelligenceSlots`. No INT-021 / R05 changes.

| Signal column | Slot trigger | Boost rule |
|---------------|--------------|------------|
| `date_night_score` | romantic / date night / anniversary | `+ score × 0.30` |
| `touristy_score` | not touristy / avoid tourist / tourist trap | `− score × 0.25` |
| `value_score` | under $N / budget / cheap / value | `+ score × 0.20` |
| `service_score` | good / great / excellent service | `+ score × 0.15` |

**Note:** Schema uses `date_night_score`, not `romantic_score`.
