## Architecture

Production-safe tracing without `@mastra/observability`. Each CopilotKit turn writes one row to `public.ai_runs` via `LoggingMastraAgent` + `logAgentRunForTurn`, persisted after SSE via `next/server after()` in `/api/copilotkit`.

```
CopilotKit POST /api/copilotkit
  → LoggingMastraAgent.run()
      → Mastra tools (runAuditedSearch / runAuditedTool)
          → recordToolSpan on shared RequestContext
      → finalize()
          → summarizeToolSpans + buildTurnTelemetryMetadata (agt-00c-v1)
          → after() → recordMastraRun → ai_runs
```

**Metadata schema:** `telemetry_version: agt-00c-v1`
