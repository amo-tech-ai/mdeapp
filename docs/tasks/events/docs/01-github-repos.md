## Best overall

**Best for mdeai:** **`match-my-sponser-web`** + selected ideas from **`altr_sponsorship_mvp`**.

Why:

* `match-my-sponser-web` is closest to your actual stack: **Next.js, TypeScript, Supabase, Vercel, real-time chat, role-based organizer/sponsor dashboards, AI matching**. ([GitHub][1])
* `altr_sponsorship_mvp` has the strongest business strategy: sponsorship OS, deal lifecycle, escrow, ROI reports, brand/event matching, and revenue model. ([GitHub][2])

## What features mdeai should adapt

### MVP+1 sponsor features

Build these after ticketing works:

| Feature                  | Why                                                    |
| ------------------------ | ------------------------------------------------------ |
| Sponsor profile page     | Brands need clear identity, budget, categories         |
| Event sponsor slots      | Hosts define Bronze/Silver/Gold/Premium placements     |
| AI match score           | “Why this sponsor fits this event”                     |
| Organizer/sponsor chat   | Replaces cold email chaos                              |
| Sponsor request workflow | Organizer sends proposal, sponsor accepts/declines     |
| ROI dashboard            | Impressions, clicks, leads, QR scans, ticket influence |
| PDF sponsor report       | Easy for brand managers to send to bosses              |

## Real-world mdeai examples

**Fashion event:** Roberto creates “Medellín Fashion Rooftop.” AI recommends beauty brands, salons, jewelry stores, fashion boutiques, and nightlife sponsors.

**Beauty contest:** AI matches cosmetics, wellness clinics, salons, and photographers to contestant categories and audience demographics.

**Startup event:** AI recommends coworking spaces, SaaS companies, fintech brands, recruiters, and AI tool companies.

## Final verdict

Use **`match-my-sponser-web` as the closest build reference**.

Use **`altr_sponsorship_mvp` for strategy**.

Use **`event-matcher` for Gemini match scoring logic**.

Do **not** copy everything. Build a focused mdeai version:

```text
Event → Sponsor slots → AI matching → Sponsor chat → Deal → ROI report
```
