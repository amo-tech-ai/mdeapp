- YAML: `id`, `title`, `phase`, `priority`, `status`, `owner_system`, `depends_on`, `unblocks`, `linear_title`, `linear_labels`, `implements`, `related_re`, `related_vec`
- Problem · User story · Example prompt · Implementation steps · Files · Data · RLS · Tests · Acceptance · Failure points · Verify command
