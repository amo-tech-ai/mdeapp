For MDE, the dashboard should be much more than "Trips".

It should be the user's **personal Medellín command center**.

## Recommended Dashboard Structure

```text
[ Search ]
```

* Find Events

## Luxury Dashboard Formula

```text
Welcome Back
        ↓
Upcoming Plans
        ↓
AI Recommendations
        ↓
Collections
        ↓
Events + Tickets
        ↓
Trips
        ↓
Reservations
        ↓
Rentals
        ↓
City Intelligence
        ↓
Map
        ↓
Stats
```

The key difference from Wanderlog is that Wanderlog is a **trip organizer**.

MDE should be a **personal city operating system** combining trips, events, tickets, restaurants, cafés, nightlife, rentals, saved places, AI recommendations, and local intelligence in one dashboard. This aligns closely with the Trips, Events, Venues, and Concierge vision already defined in the project documentation.
