### Design Direction: MDE AI Luxury Concierge Dashboard

**Reference Analysis (Wanderlog screenshot)**

What makes it feel clean:

- Large whitespace between sections
    
- Consistent card sizes
    
- Strong image usage
    
- Simple navigation
    
- Clear content grouping
    
- Minimal colors
    
- Strong visual rhythm
    
- Large section headings
    
- Easy scanning
    

What prevents it from feeling luxury:

- Generic cards
    
- Weak typography hierarchy
    
- No emotional imagery
    
- Flat visual depth
    
- Basic map integration
    
- Weak personalization
    
- Low-end stock style graphics
    
- Not immersive

For MDE specifically, the homepage should focus on **Discover → Save → Plan → Book → Experience**, with Events, Restaurants, Cafés, Nightlife, Rentals, and Trips all visually connected through the AI concierge and map experience, which aligns with the platform vision and design direction already documented.
