Map workspace — wireframe & component spec

Build-ready blueprint for the synced cards ↔ pins workspace (D-11 / SAN-577). It's the shared map layer embedded in discovery routes and /chat — "see it on the map, not a list of links." Persona: Camila / Tourist. The center of gravity is the two-way hover/focus sync.

D-11 · SAN-577 · UX-024 hover parity reuse @vis.gl ChatMap — don't rebuild mapId + X-Goog-FieldMask (hard rules) EN only · Phase 1

Global rules

  • Reuse, don't rebuild: the existing @vis.gl/react-google-maps ChatMap + AdvancedMarkers
  • Hard rules: mapId on every <Map>; X-Goog-FieldMask on every Places call
  • One card system: the D-08 VenueCard renders in the rail; pins mirror the same dataset
  • Clear stale markers on empty/new search (UX-033) — no ghost pins
  • Two-way sync is the feature: card↔pin highlight, both directions (UX-024)
  • A11y: pins are buttons (keyboard focus → same highlight as hover); prefers-reduced-motion disables pan/zoom animation
  • Perf: cluster at low zoom; virtualize the card rail; debounce "search this area"
  • Pins uniform teal; active = gold; cartography blue only for water/parks
