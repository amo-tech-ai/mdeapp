Place data fields define the types of Place data to return when requesting place details. This
page lists all of the place data fields supported by the Place class.

Fields correspond to [Place Details results](https://developers.google.com/maps/documentation/javascript/place-details),
and are divided into these categories: ID only, basic, advanced, and preferred. See
[Places API Usage and Billing](https://developers.google.com/maps/documentation/javascript/usage-and-billing)
for more information. Every call always returns an [Attribution](https://developers.google.com/maps/documentation/javascript/reference/place#Attribution)
for each result, which must be shown in your UI.
