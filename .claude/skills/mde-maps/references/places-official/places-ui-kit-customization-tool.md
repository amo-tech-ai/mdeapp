Use the Customization tool to visualize how different sets of properties will affect the appearance of a Places Details element. The **Code** tab provides configurations in HTML/CSS, Kotlin/XML, and Swift.


Refer to [Custom styling](https://developers.google.com/maps/documentation/javascript/places-ui-kit/custom-styling) for more information about how to customize your Places UI Kit elements and for a CSS properties reference table.
